# 示例 Skill：UI 设计协作助手

这是一个真实场景的 Skill 示例——帮你和 AI 高效协作设计界面。

---

## skill.md 长这样

```markdown
---
name: ui-design
description: 当用户需要设计 UI 界面、网页布局、App 页面时触发。
---

# UI 设计协作 Skill

## 设计流程

### 阶段 1：需求讨论
先问清楚：
- 这是什么产品？（网页 / App / 后台？）
- 给谁用的？（年龄、场景、设备）
- 参考风格？（有没有喜欢的同类产品？）
- 有哪些必须包含的元素？（按钮、表单、图表？）

### 阶段 2：方案草图
提供 2-3 个布局方向供选择：
- 方向 A：主推方案（说明理由）
- 方向 B：备选方案（说明差异）
- 方向 C：（如有）大胆的创意方案

### 阶段 3：细化设计
用户选好方向后：
- 1 个页面一个页面的细化
- 每个页面说明布局逻辑和设计决策
- 等待用户确认后再进入下一页

## 设计原则
- 优先考虑可用性，其次美观
- 移动端优先，再适配桌面端
- 每个页面只突出一个主操作
```

---

## 为什么这个例子好理解

- ✅ 流程复杂但有章法——三个阶段逐步推进，不会东一榔头西一棒槌
- ✅ 决策点明确——每个阶段都有用户确认的环节，不会一口气跑偏
- ✅ 展示"复杂任务"场景——不是所有 Skill 都是填模板，有的像"项目管理清单"
